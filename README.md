# FDG-PET VAE Pipeline for Dementia Classification

This repository contains code for processing FDG-PET imaging data using a Variational Autoencoder (VAE) framework combined with various machine learning techniques. The goal of the project is to extract meaningful features from FDG-PET data, explore the latent space, generate similarity maps, and perform classification tasks to assist in diagnostic analysis.

## Publication
**"Variational autoencoder latent space as a robust and pragmatic clinical classification tool for dementia"**, Alzheimer's Association International Conference, 2024, [Read the publication here](https://alz-journals.onlinelibrary.wiley.com/doi/full/10.1002/alz.093646),
[Conference page](https://aaic.alz.org/)

## Repository Structure

- **VAE_architecture.ipynb**  
  Contains the implementation of the Variational Autoencoder architecture. This notebook details the encoder and decoder networks, training and validation functions, and includes tools to visualize the reconstructed images and assess model performance.

- **feature_extraction.ipynb**  
  Implements the feature extraction pipeline. This notebook shows how to load and preprocess FDG-PET data, apply a custom dataset loader, and extract latent embeddings using the VAE.

- **latent_space.ipynb**  
  Explores the latent space generated by the VAE. It includes techniques such as PCA, UMAP, and K-Nearest Neighbors (KNN) analysis, and creates neighborhood graphs to understand the relationships among data points.

- **classifier.ipynb**  
  Contains code for performing classification tasks using the extracted features. The notebook includes implementations of logistic regression, KNN, ensemble methods, and evaluation metrics (e.g., ROC AUC, balanced accuracy) to differentiate between dementia types.

- **similarity_maps.ipynb**
  Generates similarity maps of FDG-PET data. The notebook leverages image processing libraries (e.g., nilearn and ANTs) to create 2D slice visualizations and surface renderings that highlight intensity differences and similarities.
